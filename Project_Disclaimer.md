# Project Disclaimer & Synthetic Data Attribution

## Purpose

This repository is an independent portfolio demonstration created to demonstrate data-science and product-analytics capabilities aligned with the supplied **Data Scientist, Level 4 — Growth** job description at Snap Inc.

## Synthetic Data

All users, sessions, experiment assignments, timestamps, product metrics, treatment effects, retention outcomes, and guardrail signals are synthetically generated by Python. They do not represent Snap internal data or observed Snapchat user behavior.

## No Confidential Information

The project does not use confidential Snap datasets, proprietary recommendation-system logic, internal dashboards, private algorithms, or non-public company information.

## Interpretation

Any business scenario, parameter, threshold, treatment effect, or product behavior in this repository is a modeling assumption for portfolio demonstration. It must not be represented as a factual statement about Snap's production systems or current business performance.

## Statistical Integrity

The project is designed so that the final analysis computes its own estimates. Documentation must not be updated with invented p-values, effect sizes, or launch decisions.

## Reproducibility

Random seed, sample sizes, treatment parameters, schema, metric definitions, and SQL transformations are documented so another reviewer can reproduce the analysis.
